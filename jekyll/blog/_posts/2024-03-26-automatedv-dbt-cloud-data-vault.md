On 26 March 2024 I gave a session for AutomateDV called "Build for scale, agility, and reliability with dbt Cloud, AutomateDV, and Data Vault". The recording is on YouTube.

AutomateDV is a dbt package for building Data Vault models. Data Vault produces a lot of models that share the same few shapes, and writing each one by hand is repetitive work where small mistakes creep in. The session demonstrated Data Vault automation with AutomateDV on dbt Cloud: describing the hubs, links and satellites once, and letting the package generate the repetitive SQL that implements them. With the pattern taken care of by the package and the project running on dbt Cloud, the work that is left for the team is the part that needs judgement, which is deciding how the business should actually be modelled.

The full session is available to watch on YouTube.

This session picked up the Data Vault article I wrote for the dbt Developer Blog in 2023 and put it on screen. What had been an argument in writing became something you could watch being built, step by step.
